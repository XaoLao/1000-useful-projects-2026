# 1000 Useful Projects (2026)

A curated collection of **1,000 practical software project blueprints** built around areas people actively look for: AI, automation, developer tools, productivity, local-first software, self-hosted apps, APIs, CLI utilities, browser extensions, mobile apps, 3D/WebGL, data tools, research tools and more.

Each project has its own folder with:
- a clear problem to solve
- core features
- a suggested technology stack
- starter milestones
- good first issues

## How to use this repository
Pick a project from [`INDEX.md`](INDEX.md), open its folder, and build the smallest useful version first. These are intentionally scoped as starting points rather than fake finished products.
